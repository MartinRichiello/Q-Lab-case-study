
# Output Task 6 – Causal Inference

## Where the code lives

## Summary
A Jupyter notebook analyzing whether Resolution Time has a meaningful relationship with Severity Category or Defect Category, using group comparisons, a Kruskal-Wallis test, and a logistic regression, followed by a simulation of 10%/25%/50% reductions in resolution time. The analysis finds no statistically significant relationship across all three methods, and discusses what that means for decision-making, along with an explicit correlation-vs-causation caveat given the observational nature of the data.
